# Tekservix Homebrew tap

Homebrew tap for the SMS Gora SMS Gateway and **WAservix WhatsApp API Gateway** command-line tools by Tekservix.

```bash
brew install tekservixhq/tap/tekservix
```

Installs the `smsgora` (SMS through your own Android phones) and `waservix` (WhatsApp from your own number) command-line tools. See [tekservix-cli](https://github.com/TekservixHQ/tekservix-cli) for usage.
